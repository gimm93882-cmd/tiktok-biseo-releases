# 틱톡 비서

틱톡 LIVE 호스트를 위한 매니저 앱 — 방송 판짜기 · 실시간 멘트 · 외국어 응대(스피커) · 선물 집계 · 리액션 음원 · 리액션 메뉴판 · 감사 영상.

## 받기

👉 **[최신 버전 받기](https://github.com/gimm93882-cmd/tiktok-biseo-releases/releases/latest)**

| 컴퓨터 | 파일 |
|---|---|
| 윈도우 | `틱톡비서-…-win-x64.exe` |
| 맥 (M1 이후) | `틱톡비서-…-mac-arm64.dmg` |
| 맥 (인텔) | `틱톡비서-…-mac-x64.dmg` |

## 처음 설치할 때
- **윈도우**: "Windows의 PC 보호" 창 → 「추가 정보」 → 「실행」
- **맥**: "확인되지 않은 개발자" → 앱을 오른쪽 클릭 → 「열기」 (한 번만)

설치한 뒤에는 앱이 새 버전을 알아서 받습니다. 사용법은 앱 안 「사용법」 탭에 있습니다.
